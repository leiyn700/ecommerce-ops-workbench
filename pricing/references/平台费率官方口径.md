# 平台费率官方口径与数据来源（截至 2026-09-25）

## 一、定价公式

```
售价 = 固定成本 ÷（1 − 平台费率 − 推广占比 − 目标净利率）

固定成本 = 进价 + 运费 + 包装耗材 + 退款均摊
退款均摊（每成功单）= 退货率 ÷（1−退货率）×（来回运费 + 包装耗材）
```

- 退款均摊口径依据：退货退款时货可退回二次销售（不亏货），真实损失 = 来回运费 + 包装 + 部分平台不退的支付费（金额小，计入均摊损失近似）
- 严格口径按「成功订单」摊：除以 (1−退货率)。简化口径（退货率 × 单均损失，按发货单摊）会低估
- 建议售价 = 理论最低价向上取整到个位再减 0.1（x.9 心理尾数），且不得低于理论价

## 二、各平台计费规则（官方来源）

### 小红书 ✅ 官方全表
- 来源：《2025 小红书基础技术服务费费率标准》，2026-05-05 公示、2026-05-12 生效
- 地址：school.xiaohongshu.com/rule/detail/27/2585
- 公式：基础技术服务费 =（商品货款实付 + 平台补贴 − 税金）× 类目费率，**不含运费**
- 支付渠道技术服务费 =（商品货款实付 + 运费实付）× 0.6%
- 多件商品订单按各商品类目费率分别计收
- 退款：技术服务费按退款比例退还
- 关键类目归属：香薰蜡烛/无火香薰 → 一级类目「洗护清洁剂/卫生巾/纸/香薰」2.5%；插电香薰机 → 「生活电器」2%；PPT/简历等模板 → 「个性定制/设计服务/DIY」2%；珠宝/贵金属按结算单价阶梯 1%-5%；宠物主粮 2.5%、其他宠物 5%；本地生活/服务类 5.7%

### 淘宝 / 天猫 ✅ 官方
- 来源：淘宝商家服务大厅《天猫商家基础软件服务费规则及常见问题》
- 淘宝 C 店：**无类目佣金**，仅基础软件服务费 = 确收成交金额 × 0.6%（含运费、含平台补贴）
- 确认收货后才扣费；**确认收货后发生的退款不退 0.6%**（确认收货前退款不收）
- 年确收成交金额 ≤ 12 万的商家：基础软件服务费全额现金返还（2026 年延续）→ 小卖家实际平台费 ≈ 0
- 天猫店铺：0.6% 基础软件服务费 + 类目软件服务费（2%-8%，珠宝可达 15%-20%）；年费已于 2024-09 取消
- 部分高价类目单笔订单 0.6% 封顶 60 元

### 拼多多 ✅ 官方
- 来源：《拼多多技术服务费收费规则》，2020-07-20 生效、2023-03-12 最新修订
- 基础技术服务费：普通订单 =（消费者实付 + 平台优惠）× 0.6%；**先用后付订单 =（应付 + 平台优惠）× 1%**
- 类目技术服务费：仅特定类目收取（0.5%-5% 区间）
- 百亿补贴等特定活动另有技术服务费（约 1%-3%）
- 退款：基础技术服务费不退；类目技术服务费按比例退；带「技术服务费可退」标签的活动订单随退款自动返还

### 抖音 ⚠️ 部分核实
- 来源：抖音电商学习中心《2026 基础技术服务费费率标准》（2026-07-15），地址 school.jinritemai.com/doudian/web/articlev0/aHijyoJA6hvb —— **完整类目表需商家登录查看**，公开页仅片段
- 公式（官方确认）：技术服务费 =（消费者实付金额 **含运费** + 主播优惠券/红包 + 平台优惠券/红包）× 类目费率；商家券不计入
- 订单技术服务费 = 基础技术服务费 + 特定渠道补充技术服务费（如精选联盟渠道）
- 2026 年政策：使用「千川·乘方」的订单技术服务费降至 0.6%；商品卡/全场景免佣活动随时期变化
- 保证金：0 元试运营（≤200 单且 ≤1 万 GMV），之后按月 GMV 500-5000 元

### 快手 ⚠️ 未核实
- 官方规则中心（edu.kwaixiaodian.com）仅公开本地生活/团购类费率（餐饮 2.5%、丽人 5%、住宿 4.5% 等）；实物电商《快手小店资费一览表》在登录墙后
- 二手资料区间：1%-5%（图书农副 1%-2%、服饰百货 2%-5%）
- 结算口径（官方确认）：订单成交金额 = 消费者实付（含运费）+ 主播券/红包 + 平台券/红包，不含商家券
- 退款：售后期内未结算的退款扣减后结算；已结算的按比例退回

## 四、更新数据的规则

1. 优先级：商家后台「结算规则」> 官方规则中心公示文档 > 行业媒体（网经社等）> ❌ 禁止采信 AI 聚合内容（爱企查 AI 问答等）作为唯一来源
2. 修改 HTML 内 `CATS` 的 rates 后，同步更新：
   - 顶部数据状态注释
   - `catEst()` 的核实平台标记
   - 卡片下方 hint 说明文字
3. 费率未核实的平台必须在界面上保留提醒标签，不得静默充当官方数据
