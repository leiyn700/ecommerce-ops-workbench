# 核算口径

引擎实现在 `assets/engine/compute.js`（口径）与 `assets/engine/ingest.js`（取数与表头识别）。
本文与二者严格对应；改口径必须同步改这份文档。

## 一、输入

| 表 | 必备 | 作用 |
|---|---|---|
| 订单导出（千帆「包裹详情」等） | 是 | 销售额、件数、运费、退款、时间 |
| 拿货价参数表 | 强烈建议 | 成本。缺了只能按 0 成本算，利润虚高 |

参数表只要两列即可：`规格ID`（或 规格编码 / 规格） + `拿货价（元）`（或 拿货成本 / 成本价 / 进价 / 成本）。

## 二、表头识别

真实导出文件前面常有标题行（如「导出时间 2026-09-05」），所以**不假设第一行是表头**：

> 取前 10 行中，命中必需列最多的一行作为表头行；命中数相同时，比这一行的非空格数。

必需列四个，缺任何一个都算不出核心指标：

| 逻辑字段 | 认的列名（按优先级，先精确后包含） |
|---|---|
| `rec` 商家应收金额 | `商家应收金额(元)（支付金额）` → `商家应收金额(元)(支付金额)` → `商家应收金额` |
| `ss` SKU规格 | `SKU规格` |
| `fr` 包裹总运费 | `包裹总运费(元)` → `包裹总运费` |
| `t` 支付时间 | `支付时间` |

其余可选列：订单号、订单状态、售后状态、规格ID、SKU名称、SKU件数、用户应付金额、商品总价、
平台优惠、店铺优惠、支付渠道优惠、SKU商家改价、省、市、商品ID、商品名称、达人名称。

数值清洗：去掉 `,`、空格、`￥`、`¥`、`元`；空值 / `-` / `--` 视为无值（不当 0 处理，因为
「没填」和「填了 0」在缺价判断里含义不同）。

## 三、退款与有效行

售后状态值落在 `无 / 无售后 / 否 / 未申请 / 无退款 / - / / / 正常 / 无退货退款` 之内 → 该行有效，
否则视为退款行。

- **整单退款**：某订单的**所有行**都是退款行
- **有效订单** = 订单总数 − 整单退款订单数
- **退款率** = 整单退款订单数 ÷（有效订单 + 整单退款订单数）
- **金额与件数一律只统计有效行**——退款行不再重复计入运费与优惠，
  否则同一单会一头扣销售额、一头又扣运费

## 四、指标口径

```
净销售额   = Σ 有效行「商家应收金额」
成交件数   = Σ 有效行「SKU件数」（缺失按 1 件）
拿货成本   = Σ 各规格（拿货价 × 该规格有效件数）
毛利       = 净销售额 − 拿货成本
毛利率     = 毛利 ÷ 净销售额
包裹运费   = Σ 有效行「包裹总运费」
履约后利润 = 毛利 − 包裹运费
经营利润   = 履约后利润 − 平台扣费 − 推广费
客单价     = 净销售额 ÷ 有效订单
退款额     = Σ 退款行「商家应收金额」
ROI        = 净销售额 ÷ 推广费（推广费为 0 时不出 ROI）
```

**店铺优惠不重复扣**：商家让利已含在「商家应收金额」里。
**平台优惠不扣**：平台出的钱，平台结算时补给商家。
**SKU商家改价**只做记录，不参与计算。

### 两个必须说明的边界

1. **平台扣费与推广费订单表里没有。** 由用户在页面上手填，存本机（不必每期重填）。
   不填按 0 算，此时经营利润是**上限估值**——要在卡片文案里讲明，不要假装精确。
   ROI 只在填了推广费时才有值。
2. **月度趋势是分摊值。** 利润按各月销售额占比摊到各月（口径写清楚），不是按月实算——
   因为拿货价、平台扣费、推广费都是**整期一个数**，没有月度粒度。
   展示时必须标明这一点，否则会被当成真实月度利润。

### 上限与截断

订单行数超过 **5000 行** 只取前 5000 行，并在预警里说明。

## 五、分层（与建议价相互独立）

按**净销售额**在「本期有成交的规格」里分位：

| 层 | 区间 |
|---|---|
| 爆款 | 前 25% |
| 潜力款 | 25% – 50% |
| 常规款 | 其余 |
| 滞销款 | 本期 0 成交（含参数表里有、订单里一行都没有的规格） |

分层看的是**规模**，建议价看的是**赚钱效率与风险**，两套判断不要混着解释。

## 六、缺数据的降级（三档，必须让用户看见）

| 情况 | 行为 |
|---|---|
| 没传参数表 | 全部按 0 成本算，利润明显虚高 —— 必须明确提示补传 |
| 参数表里缺某规格的拿货价 | 该款标为「待核数据」，卡片上直接写明「成本按 0 算，利润是虚的，先补价再谈调价」 |
| 没填平台扣费 / 推广费 | 按 0 算，经营利润偏高；ROI 不出值 |

**缺数据的款也要出现在结果里。** 零成交的规格不能只写进一行提示文字——
「哪些款一件没卖」恰恰是最该被处理的信息，必须建卡片（详见 `踩坑清单.md`）。
